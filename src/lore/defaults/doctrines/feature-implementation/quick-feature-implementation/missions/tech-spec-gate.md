# Tech Spec Gate

This mission belongs to the human. The orchestrator does not claim it and does not complete it.

## How It Works

The human reads the Tech Spec and writes what they think directly into it. Feedback has no required format — the Phase 3 missions read whatever is there.

## Hard Rules

- The orchestrator never marks this mission done on the human's behalf
- Feedback goes into the Tech Spec, not into a new document

## Inputs

The Tech Spec ID, from the board: `lore show <mission-id>`

## Steps

- Read the Tech Spec from your board: `lore show <mission-id>`.
- Read it: `lore codex show <tech-spec-id>`.
- Append your feedback directly to the Tech Spec file — no specific format required.

## Done Criteria

The Tech Spec carries the human's feedback.

Mark done.

## Hands On

The annotated Tech Spec, to Phase 3.
