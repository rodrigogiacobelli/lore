# PRD Review

This mission belongs to the human. The orchestrator does not claim it and does not complete it.

## How It Works

The human reads both Phase 1 documents and writes what they think directly into the PRD Draft. Feedback has no required format — the prd-final mission reads whatever is there and incorporates it.

## Hard Rules

- The orchestrator never marks this mission done on the human's behalf
- Feedback goes into the PRD Draft, not into a new document

## Inputs

Both document IDs, from the board: `lore show <mission-id>`

## Steps

- Read both documents from your board: `lore show <mission-id>`.
- Read both: `lore codex show <crazy-prd-id>` and `lore codex show <prd-draft-id>`.
- Append your feedback directly to the PRD Draft file — no specific format required.
- If ideas from the Crazy PRD are worth keeping, include them in your feedback.

## Done Criteria

The PRD Draft carries the human's feedback at the bottom.

Mark done.

## Hands On

The annotated PRD Draft, to prd-final.
