# Tech Spec Review

This mission belongs to the human. The orchestrator does not claim it and does not complete it.

## How It Works

The human reads both Phase 2 documents and writes what they think directly into the Tech Spec Draft. Feedback has no required format — the tech-spec-final mission reads whatever is there and incorporates it.

## Hard Rules

- The orchestrator never marks this mission done on the human's behalf
- Feedback goes into the Tech Spec Draft, not into a new document

## Inputs

Both document IDs, from the board: `lore show <mission-id>`

## Steps

- Read both documents from your board: `lore show <mission-id>`.
- Read both: `lore codex show <crazy-tech-spec-id>` and `lore codex show <tech-spec-draft-id>`.
- Append your feedback directly to the Tech Spec Draft file — no specific format required.
- If ideas from the Crazy Tech Spec are worth keeping, include them in your feedback.

## Done Criteria

The Tech Spec Draft carries the human's feedback at the bottom.

Mark done.

## Hands On

The annotated Tech Spec Draft, to tech-spec-final.
