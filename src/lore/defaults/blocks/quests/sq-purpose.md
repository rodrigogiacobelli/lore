# Start Quest

Start a new Lore quest from a doctrine. Use this when you have a feature, bugfix, or change to implement and a doctrine to
drive it. You need from the user the doctrine id (for example `feature-implementation`), a description of the change as
detailed as possible, and optionally which phases to include for a trimmed run. If either of the first two is missing, ask.
