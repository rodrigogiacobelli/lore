### 4. Create or edit the artifact

Write the file yourself under `.lore/artifacts/` (a subdirectory is a group), named `<slug>.md`. You own what the CLI
would have done: the frontmatter carries exactly `id`, `title` and `summary`, and `id` equals the filename stem. To retire
an artifact, delete the file.
