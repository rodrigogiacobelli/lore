## Link it from the codex

Linking runs one way, codex to rite: a codex document names the rites it governs in its `rites:` frontmatter field, and
rites carry no back-link. Identify the document this rite supports and add the rite's id to it; see
`references/codex-doc.md` for the edit.

This is a frontmatter-only change; it writes no prose. The link is a secondary discovery path (an agent still finds the
rite by scanning the list), so an unlinked main rite is fine. An unused shared step is not.
