## Step 3: Read `codex.md` first

`.lore/codex/codex.md` is the project-wide guide to the documentation set: the layers, the conventions, the rules every
codex document follows, and project-specific guidance that exists nowhere else. Read it before you draft. You also own
keeping it current: when a change introduces a new convention, layer, document category or project-wide rule, update it so
the next reader finds the rule from the top. It is lean by design; never add per-doc summaries or per-feature notes.
