## Step 2: Follow the links

From the most relevant document, read its `related` ids and open those documents: the graph is the `related` field.

## Step 3: Cross to code

A `binds:` field lists the code files the document governs. When a search lands on a technical or standards document, read
those files if the question is about implementation.
