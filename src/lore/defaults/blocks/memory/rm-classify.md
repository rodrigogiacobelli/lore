A "what / why / where" question is codex; a "how do I" question is a rite. Many questions carry both ("what is our refund
policy *and* how do I issue one"), and then you run both.

## The bridge runs one way

A codex document names the rites it governs in its `rites:` frontmatter field. Rites carry no links back. So start in the
codex: find the governing document, read it for the *what*, then follow its `rites:` field to the *how*. If you start from
a rite, find the codex document by searching for it.

## Step 1: Classify and enter

Decide what the question is really asking, then pick the entry point.
