## Step 5: Answer, citing what you used

Stitch the factual and procedural halves into one answer. Cite codex ids for facts and rite ids with the conclusion you
reached for procedures, so the user can go read the same thing. If a surface does not hold the answer, say so plainly for
that half rather than inferring across the gap. A missing procedure is a signal to record one, not to improvise one.
