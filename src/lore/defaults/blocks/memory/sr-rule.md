## The rule

Every difference between the seed and the project file falls into one of two buckets:

- **Generic**: describes how *Lore or the codex* works: a command, a frontmatter field, a layer definition, a
  content-class rule, a naming convention. **Sync it** into the project file.
- **Project-specific**: describes *this project's* domain, examples, chosen layer set, or local conventions. **Leave it
  alone.**
