Run several searches when the topic has angles: entity, workflow, command or table name. Searching for a concrete artifact (a
table, an endpoint, an event, a job) usually lands on a `ref-<system>-<concept>` cluster document under
`technical/<domain>/ref/`; those hold intent (history, gotchas, constraints nothing enforces), and name where the schema
lives in code.
