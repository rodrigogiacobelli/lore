## Writing a name and a summary

- **`name`**: what a reader would call this group, not the hub's title repeated.
- **`summary`**: what the group covers and what question it answers, for someone who has read nothing. Name the concrete
  subjects, so a keyword search lands here.

A cluster that resists description usually shares links but not a subject. Say so in the summary rather than inventing a
theme.
