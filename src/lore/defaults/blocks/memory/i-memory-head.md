## Project memory

The **codex** (`.lore/codex/`) holds what is true about the project, the **rites** (`.lore/rites/`) hold how to do
or diagnose a recurring task, and the **glossary** (`.lore/codex/glossary.yaml`) holds its vocabulary. Read them
before you act and record what you learn.
