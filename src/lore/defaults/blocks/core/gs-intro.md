# Getting started with Lore

Lore's setup created the `.lore/` directory you are reading from and wired your agents up itself; there is nothing to
copy by hand. Run in a terminal it asked which Lore features the project uses and how agents reach each one, then
printed every file it would create, replace or remove and waited for your confirmation. Run from a pipe, a CI job or
the Python API it prompted for nothing and took its answers from flags, from `.lore/config.toml` and from its
defaults.
