### 4. Create or edit

Write `.lore/watchers/<name>.yaml` yourself (a subdirectory is a group), changing only the field the request names when
you edit. You own what the CLI would have done: a valid definition and a filename that is the watcher's name. To retire a
watcher, delete the file.
